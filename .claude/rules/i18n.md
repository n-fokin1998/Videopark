# i18n rules

Spec: [docs/i18n.md](../../docs/i18n.md). Launch locale: `ru`; planned: `uk`, `en`.

- **No user-facing string literals** in components, layouts or pages (including `aria-label`, `alt` fallbacks, `title`, button text).
  Use `t('key')` from `src/i18n`. Add new keys to `src/i18n/ui/ru.ts` (source of truth; other locales are type-checked against it).
- Keys are namespaced and semantic: `station.music.name`, `player.play`, `history.nameOrigin.title`. Not `button1`.
- Plurals via the `plural()` helper (`Intl.PluralRules`); never `n + ' треков'`.
- Dates and numbers via `src/lib/dates.ts` / `Intl`; partial dates must render with their real precision («2017», «март 2017»).
- Links between pages are built with `localizedPath(path, locale)` — never hard-code `/music` with a locale assumption.
- Set `lang` on `<html>` from the current locale and on any element whose content is in another language (lyrics on `uk`/`en` pages are `lang="ru"`,
  French poem titles `lang="fr"`).
- Song/release titles, lyrics and quotes are **never** translated in place; translations are separate, labelled, credited.
- Content translations use locale-suffixed files (`*.ru.md`, `*.uk.md`, `*.en.md`) or `localized` fields `{ ru, uk?, en? }`.
- Fonts and UI must support Ukrainian glyphs (і ї є ґ ʼ). Test with «Бровари, ґанок, їжак».
- Don't enable a locale in `src/i18n/config.ts` until its UI strings are complete and the core pages are translated and reviewed.
