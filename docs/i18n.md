# Internationalisation

**Launch:** Russian only (`ru`) — the language of the songs and of the research.
**Planned:** Ukrainian (`uk`) and English (`en`).

The architecture is multilingual from the first commit so that adding a locale is translation work, not a refactor.

## 1. Sensitivity note

Zhenya was a Ukrainian artist from Brovary who sang in Russian, and said: «Я пою на том языке, на котором мне комфортно петь… важны сами слова».
The site respects this: lyrics and quotes stay in their original language everywhere; interface and editorial text are localised.
Ukrainian should be added as soon as feasible and given equal standing with Russian (full parity, not a partial translation).
Never present the project as part of the "Russian scene" — he explicitly rejected that.

## 2. Routing

Astro i18n routing:

```js
// astro.config.mjs
i18n: {
  locales: ['ru', 'uk', 'en'],       // uk/en pages are generated only when enabled in src/i18n/config.ts
  defaultLocale: 'ru',
  routing: { prefixDefaultLocale: false },   // ru: /music, uk: /uk/music, en: /en/music
  fallback: { uk: 'ru', en: 'ru' },          // only if we decide to show untranslated pages; otherwise hide the locale switch per page
}
```

- Route slugs are identical in all locales (`/music`, `/lyrics/plavitsya-lyod`), only the prefix changes. Simple, shareable, stable.
- `src/i18n/config.ts` holds `enabledLocales` (launch: `['ru']`). `getStaticPaths` generates pages only for enabled locales.
- Russian pages are plain files in `src/pages/` (`music/index.astro` → `/music`). A future locale gets `src/pages/[locale]/…` routes whose
  `getStaticPaths()` returns `enabledLocales` minus `ru`; station pages are thin wrappers around `StationLayout`, so this is a few lines each (D-024).
- Helpers: `localizedPath(path, locale)` builds links, `parseLocalizedPath(pathname)` splits a URL into locale + path (`src/i18n/routes.ts`).
- `hreflang` alternates and `x-default` (→ `ru`) emitted by `BaseLayout` for every page that exists in multiple locales.
- **Decided (D-007):** Russian is served without a prefix (`/music`); Ukrainian and English are prefixed (`/uk/music`, `/en/music`).
  Do not switch to `prefixDefaultLocale: true` — it would break published URLs.

## 3. UI strings

- All interface strings live in `src/i18n/ui/<locale>.ts` as a typed nested object; `ru.ts` is the source of truth and defines the key type.
- Access via `t('station.music.name')` / `useTranslations(locale)`. No hard-coded user-facing strings in components (lint-checked where possible).
- Plurals via `Intl.PluralRules` (`ru`/`uk` have one/few/many/other): helper `plural(locale, n, forms)`.
- Dates/numbers via `Intl.DateTimeFormat` / `Intl.NumberFormat` with partial-date support in `src/lib/dates.ts`
  (e.g. `2017-03` → «март 2017» / «березень 2017» / "March 2017").
- Station names are UI strings: Платформа / Платформа / Platform; Музыка / Музика / Music; История / Історія / History; Тексты / Тексти / Lyrics;
  Фото / Фото / Photos; Видео / Відео / Video; Бровары / Бровари / Brovary; Женя / Женя / Zhenya.
  (Deferred station, if it returns: Воспоминания / Спогади / Memories.)
- The wordmark «Станция Видеопарк» stays Cyrillic in all locales (EN may add «Videopark Station» as a secondary line). In the name-origin
  scene the signs «Гидропарк» / «Видеопарк» stay in the original; the translated story text explains the pun (Hydropark → "Videopark").

## 4. Content localisation

| Content | Translated? | How |
|---|---|---|
| Song & release titles | **No** — always original | Optionally a transliteration/translation shown as secondary text in `en` |
| Lyrics | **Never replaced** | Optional translation files shown side-by-side, labelled «Перевод: …» with translator credit |
| Quotes | Original always shown | Translation underneath, labelled |
| The «Сторона» interview | Original | Translation as parallel text |
| Biography, eras, writings intro, places, about | Yes | Locale-suffixed markdown files |
| Short data fields (titles of events, captions) | Yes | `localized` objects `{ ru, uk?, en? }` |
| Instagram captions | No | `lang` attribute set |

File conventions:
- Long-form: `content/pages/zhenya.ru.md`, `zhenya.uk.md`, `zhenya.en.md`; `content/eras/2019-raw-pop-syndicate.ru.md`, …
- Lyric translations: `content/songs/plavitsya-lyod.md` (original) + `content/songs/translations/plavitsya-lyod.en.md` (`translator`, `note`).
- Missing translation → page for that locale is not generated (or falls back with a visible notice, per decision).

## 5. Typography & `lang`

- Every element whose language differs from the page locale gets a `lang` attribute (lyrics on an `en` page: `lang="ru"`; Desnos's French title: `lang="fr"`).
  This drives hyphenation, screen-reader pronunciation and Pagefind.
- Fonts must include Ukrainian glyphs (і ї є ґ ʼ). Test strings: «Бровари, ґанок, їжак, є, ʼ».
- RU/UK typographic rules (non-breaking spaces, «ёлочки», em dashes) applied by the typograf build step for `ru` and `uk`; English uses “curly quotes”.

## 6. Transliteration

- Slugs: a fixed RU→Latin table (`src/lib/slug.ts`), unit-tested, never changed after launch.
- Display transliteration of names for `en`: Ukrainian national transliteration for Ukrainian names/places (Brovary, Yevhenii Mychak / "Zhenya"),
  conventional English forms for others (Robert Desnos, Ilya Kormiltsev). Keep a glossary in `src/i18n/glossary.ts`.

## 7. Checklist for adding a locale

1. Add `src/i18n/ui/<locale>.ts` (type-checked against `ru.ts`).
2. Translate pages, eras, places, people bios, captions (writings and lyrics stay original; translations optional and labelled).
3. Add lyric/quote translations where available (optional).
4. Enable the locale in `src/i18n/config.ts`; show the language switch in «Схема».
5. Native-speaker review of tone against [editorial-guidelines.md](editorial-guidelines.md).
6. Verify `hreflang`, sitemap, OG images, Pagefind per locale.
